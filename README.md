这是一个以国内商品为主线的盘后研究工作台。它把行情、均线、量仓、席位、偏离过程及已取得的产业资料组织成可核查的研究线索，并分别保留独立核对项和缺失资料。

研究入口聚焦 **油脂油料、有色金属（含贵金属）、黑色** 三个板块，目前展示34个品种。采集层保留更广的市场样本；具体覆盖、数据日期和来源状态以网页为准。在线网页显示最近成功发布的快照；下载的离线 HTML 内嵌数据、样式和脚本，不会自行联网更新。

## 研究思路：分别回答三个问题

| 层次 | 要回答的问题 | 主要证据 | 当前判断边界 |
| --- | --- | --- | --- |
| 盘面状态 | 价格、持仓和席位样本正在呈现什么状态？ | 后复权连续均线、真实合约价仓象限、公布的会员排名 | 指标包含重复价格信息，不是独立投票，也不是综合供需判断 |
| 偏离与修复 | 价格离均线多远？偏离在扩大还是收敛？ | 历史MA20、ATR14、首次触发、最远偏离及后续收盘 | 识别观察过程，不把偏离直接解释为必然反转 |
| 基本面核对 | 实物与产业资料是否提供对应线索？还缺什么？ | 同口径库存、仓单、实际统计、年度预测、订单和基差的可用情况 | 证据不足时保留“部分证据”，不强行判为支持或抵触 |

使用时先确认日期、合约和流动性，再查看盘面与偏离过程，最后进入品种研究，核对国内供需、库存和宏观传导。研究记录需要同时写出：已有事实、可能的解释、反向证据、尚缺资料，以及接下来观察什么。

例如，“均线偏空”和“当日反弹”可以同时成立；“价格上涨与某交易所去库并存”也不能直接证明需求改善。页面通过并列展示这些事实，保留需要进一步验证的解释。

## 一、盘面状态：描述已发生的变化

### 后复权连续研究与真实合约

价格研究使用**固定基准、比例后复权主力连续序列**，用于MA5/MA20、ATR、偏离事件、5/20日收益、波动和横截面强度。该序列由本站根据逐合约原始行情构建，保存来源、研究对应合约、选择日期、因子及换月记录，不把未经核实的“主力连续”接口直接当作已复权数据。

真实报价、成交量、持仓量、席位、库存价格对照和期限结构继续使用具体合约。官方全合约数据可用时，真实代表合约在当日有成交且收盘有效的标准合约中选择持仓量最大者；它可能与连续研究规则选中的合约不同，页面分别标注。

连续规则固定为：首个有效样本以持仓量最大的合约为基准，初始因子为1；T日依据T−1收盘后已知持仓，只有远月持仓超过当前研究合约的1.1倍时才切换，不回切到近月。切换时使用前一交易日两合约的有效收盘价：

```text
新因子 = 旧因子 × 前日旧合约收盘价 ÷ 前日新合约收盘价
研究OHLC = 该日研究对应真实合约OHLC × 因子
```

OHLC统一应用同一比例因子；成交量、持仓、席位和资金数量不复权。新旧合约价差不直接算成换月当日收益，后续更新延伸已发布序列，保留既有基准和历史点。换月需要相邻交易日、前日新旧合约收盘与持仓、切换日有效成交OHLC；任一必要环节缺失则停止延伸并标注数据不足，连续指标留空，不用固定合约或不复权主连默替。

该1.1倍规则是本站公开研究规则，不声称与某数据商主力定义完全一致。[米筐连续合约接口的参数定义](https://www.ricequant.com/doc/rqdata/python/futures-mod)仅作为复权方法的文档参考，不表示已调用其接口、取得数据权限或完成数据对照；本站当前没有接入RQData。后复权价不是当前可成交价格，也不等于含移仓、手续费和保证金影响的策略实际收益。

| 均线标签 | 判定条件 |
| --- | --- |
| 均线偏多 | 后复权研究收盘 > MA20，且 MA5 > MA20 |
| 均线偏空 | 后复权研究收盘 < MA20，且 MA5 < MA20 |
| 均线分化 | 收盘价与MA5相对MA20的位置未同时指向同一侧 |
| 样本不足 | 不具备相应完整窗口，不补造均线 |

趋势全景的走势缩略图、均线与偏离使用后复权连续价，同时标注当日连续研究表现及距MA20的ATR距离；真实报价列保留实际合约原价。品种证据侧栏可展开最近60个样本的后复权走势图（同时标注总样本数）和逐次换月明细。均线偏空时较昨收上涨，显示“当日反弹”；均线偏多时较昨收下跌，显示“当日回落”。这些是当天的价格事实，不是趋势反转确认。

### 研究矩阵：方向、当日状态与核对项分开

矩阵不再将大量不同情况统一归为“存在分歧”。它分别展示连续均线方向、真实代表合约当日状态，以及独立核对项。顶部统计展示均线偏多、均线偏空、偏空中的反弹、均线分化与样本不足；三个板块仍上下排列，板块内品种横向排列。

| 连续均线方向 | 真实代表合约较昨收表现 | 当日状态 |
| --- | --- | --- |
| 均线偏空 | 上涨 / 下跌 | 偏空中的反弹 / 偏空同向下行 |
| 均线偏多 | 上涨 / 下跌 | 偏多同向上涨 / 偏多中的回落 |
| 均线分化 | 上涨 / 下跌 | 均线分化·当日上涨 / 当日下跌 |
| 任一有效方向 | 涨跌为零 / 昨收不可用 | 当日持平 / 当日涨跌缺失 |
| 连续均线窗口不足 | 任意 | 趋势样本不足 |

均线条件见上表；当日涨跌使用真实代表合约的收盘到昨收收益，不用昨结算，也不把真实合约价格拼入连续均线。增仓、减仓、持仓持平及持仓变化缺失另外显示。页面其他位置若使用连续序列当日涨跌，会单独标注口径，两者可能不同。上述状态描述已经发生的事实，不确认未来走势或趋势反转。

“席位样本差与均线反向”“席位存量差与增减项差反向”“低流动性”分别列为核对项；连续均线、真实合约昨收、持仓或席位缺失单列。没有触发核对规则不代表无风险，数据齐全也不代表判断可靠。缺少席位不会抹去已知均线方向和当日表现。筛选支持均线方向、偏空反弹、偏多回落、席位待核对、数据待补及原有偏离、放量等条件；CSV导出包含这些状态、核对项与严格同向标记。

**“严格同向”保留为辅助筛选，条件没有放宽：**均线有明确方向；当日同一真实合约增仓且价格同向；公布买卖排名样本差同向；未检测到席位存量差与已取得的当日增减项差反向。缺失值不补零。零个结果可以正常出现，不为产生多空信号调整门槛。

这些观察不是三份独立证据，均线和价仓均使用价格；严格同向不是综合多空评级，也未验证历史胜率、未来收益或因果关系。为兼容既有脚本，JSON中的 `analysis.status` 等旧字段保留；网页主要状态及CSV使用新的 `analysis.marketState`，不再用旧综合标签概括品种。

会员买单、卖单排名是两个独立集合，分别按各自名次取样。样本差不是全市场净多空，不代表会员自营观点或真实资金流；当日增减项也不是固定会员组的连续资金迁移。当前只使用快照当日排名，不生成连续席位迁移或历史净多分位。席位核对项不会改变均线方向或当日状态。

验证：`python -m unittest discover -s tests -q` 覆盖方向与涨跌组合、持平和缺失、席位对状态的隔离；`node scripts/check_market_states.cjs` 检查实际快照的筛选、严格同向兼容性及CSV字段对齐，并已加入自动发布检查。

### 流动性与持仓口径

代表合约当日成交量或持仓量低于1000手时，显示“低流动性·谨慎解读”。1000手是透明的提示规则，尚未分品种校准；系统保留原始数据和统计范围，不把稀疏成交与活跃合约的参考价值等同。

品种全合约合计与代表合约数据分开展示。合计持仓增加不能直接称为资金净流入，同一合约的持仓变化也可能受到移仓换月影响。

市场概览的“增减仓观察”是跨品种排行，不随单个合约选择变化。默认使用**已取得合约样本**：仅汇总行情日同日合约的有符号持仓增减项，显示合约数及可计算品种数；这不代表交易所全合约覆盖。任一同日合约增减项缺失或合约重复，该品种不参与计算，不补零。另可切换**全合约合计**，仅接受明确标记为全合约且有有效总增减仓的品种；不会将样本合计混入。无可用数据与有数据但该方向没有样本分别提示。两个口径均不表示真实资金流入或流出。

## 二、均值偏离：从触发到修复的过程

偏离距离定义为：

```text
偏离距离 =（后复权连续收盘价 − 当日MA20）÷ 简单ATR14
```

ATR14为最近14个真实波幅的简单平均；真实波幅取当日高低差、最高价相对昨收的绝对差、最低价相对昨收的绝对差的最大值。ATR为零或相应窗口不完整时，不生成有效偏离距离。

- 距离 ≥ +2 ATR：进入上方偏离观察，关注回调风险。
- 距离 ≤ −2 ATR：进入下方偏离观察，关注反弹可能。
- 距离退出上述阈值：继续保留至最近阈值触发后的第5个交易日，观察修复过程；超过跟踪期限后退出。
- 缺失有效历史样本或ATR失效会中断事件；后续重新满足条件时建立新观察事件。

每个事件记录样本内首次触发、最远ATR及日期、最近触发日期、当前距离、当前阶段和价均差收敛幅度。页面可区分“偏离持续、偏离扩大、偏离收敛、阈值内修复、越过均线”，并提供“修复跟踪”筛选。

“首次触发”仅指当前可用样本内的首次观察，不声称覆盖该品种全部历史。每个历史时点都只使用截至当时的同口径后复权OHLC计算MA20和ATR14，不读取后续记录。

价均差收敛使用最远ATR时点的绝对价格—均线差作为参照：

```text
同侧时的收敛幅度 = 1 − 当前 |收盘 − MA20| ÷ 最远ATR时点 |收盘 − MA20|
```

展示值限制在0%至100%；跨越均线记为该侧价均差已收敛至100%，同时单独标注阶段。最远ATR时点不一定是绝对价格—均线差最大的时点。均线移动也会影响收敛，因此该数值不是价格收益率；ATR扩大使标准化距离下降，也不能单独当作价格已经反弹。

“盘中越界后收回”只描述当日高低收相对此前20日区间的位置，“当日反弹／回落”只比较昨收。它们都不等于趋势反转。**2 ATR和5日跟踪窗口是初始观察规则，尚未完成分品种校准、策略回测或反转概率验证。**

## 三、基本面：独立交叉核对，不机械打分

品种详情中的独立交叉核对区，把盘面事实与已取得的实物、产业证据放在一起阅读，不给库存变化追加一张多空票。

### 库存与价格必须对齐

每条库存序列分别使用相邻两个已取得样本，展示实际起止日期、原单位、数量变化及来源。只有两个日期都存在同一固定合约的有效收盘价时，才计算对应价格变化；缺少端点时不拼接其他日期或交割月。晚于行情快照的库存样本不进入这项对照。

| 同区间观察 | 页面提供的研究线索 | 仍需核对 |
| --- | --- | --- |
| 价格上涨、该口径去库 | 两项变化方向相容 | 是需求改善，还是供应减少、库存转移？ |
| 价格下跌、该口径累库 | 两项变化方向相容 | 是需求减弱，还是到货增加等供给变化？ |
| 价格上涨、该口径累库 | 存在需要解释的交叉线索 | 到货、需求及价格预期是否处在不同阶段？ |
| 价格下跌、该口径去库 | 存在需要解释的交叉线索 | 是否存在供应收缩、库存转移或需求预期变化？ |

这些对应关系只描述该来源、该日期区间，不是因果识别，也不代表全部市场供需。

### 仓单、库存、产量和消费分别阅读

- **注册仓单**反映注册与注销等交割口径变化，不能直接视为终端消费。仓单与库存不相加，仓库与厂库、官方与备用来源不随意拼接。
- **交易所库存**只是特定范围的实物库存，不冒称社会总库存；不同来源的覆盖范围和单位分别保留。
- **实际统计**按原口径展示。加工产量、终端产量和行业总量可以是需求关联线索，但不能直接等同于该品种消费。
- **年度预测**与已实现产销分开展示，预测修订不是实际增减产。
- **缺失证据**逐品种列出，例如企业开工、连续订单、周度提货、进口到港、现货基差和消费结构。

数据已接入不等于研究链条完整。若局部库存和产业代理仍不足以验证判断，页面保留“部分证据，尚不能形成综合多空结论”，不强行归为基本面支持或抵触。

## 四、每个品种的四个研究维度

| 维度 | 研究重点 | 当前实现 |
| --- | --- | --- |
| 宏观驱动 | 政策、汇率、利率及产业变化如何传到具体品种？什么条件会使传导减弱？ | 34个品种分别配置传导路径、观察变量、失效条件和已有资料；未接入实时政策事件及市场一致预期 |
| 供需逻辑 | 国内供应、国内需求、供需矛盾分别有什么证据？ | 自动产业序列与人工核对资料分开；明确单品统计、产业链关联、终端代理及预测属性，海外资料作补充 |
| 库存变化 | 库存是否变化？是哪个范围和口径？ | 分来源显示实际数量、日期、单位和历史，区分实物库存与仓单注册量，披露采集失败和旧值 |
| 合约结构 | 同日不同交割月的结算价如何排列？ | 只用同品种、同日、有成交且结算价有效的合约，按实际月份间隔绘图；月差为“最近有效合约减远月合约” |

例如，黄金侧重实际利率、人民币汇率及国内投资配置；铜侧重电网制造投资与进口成本；豆粕侧重养殖利润、饲料需求与压榨；螺纹钢侧重施工资金、新开工与钢厂利润。宏观路径是条件式研究框架，不自动归因当天涨跌。

合约不足两个时不绘制期限曲线。结算价不是现货价；系统目前没有完整现货基差，也没有据此生成同一合约对的历史月差变化。用户提供的LME铜截图作为未独立核验的海外历史参考折叠保留，与境内行情分开。

## 五、指标与比较口径

| 指标 | 计算或使用方式 |
| --- | --- |
| 5／20交易日收益 | 固定基准比例后复权连续收盘收益，按共同交易日历取端点；量仓不混入该价格序列 |
| 表格日涨跌幅 | 有可核实昨结算价时，使用收盘相对昨结算价；与后复权连续研究对应合约的昨收基准分开 |
| 横截面强度分位 | 按20日收益计算经验中位秩，同值同分位；只纳入具有有效后复权连续收益的采集层样本，不混入固定合约收益；不局限于展示的34品种 |
| 板块广度 | 按页面展示范围统计正收益数量及收益中位数，不是板块指数 |
| MA20五日斜率 | 当前MA20相对5个交易日前MA20的变化率 |
| 历史波动率 | 最近20个对数收益的样本标准差 × √252，只描述历史波动 |
| 量比 | 当日代表合约成交量 ÷ 前20交易日平均成交量，基准排除当日；1.5倍为放量观察门槛 |
| 收盘突破 | 收盘相对此前20交易日高低区间，参考窗口排除当日 |
| 五日价仓地图 | 横轴为固定合约价格变化率，纵轴为同合约持仓变化率，使用线性坐标 |

价仓地图默认主体区间为持仓变化−100%至+100%。超出范围的品种单独列出真实起止值和变化率；可切换全部范围，不把异常值压在图形边界。低基数和移仓可能放大持仓变化率，持仓变化不代表价格变化或真实资金流。

上述统一窗口和门槛方便筛选，但并未证明对所有品种有相同预测意义。新增指标前应先明确它补充哪类证据，避免重复计算价格信息后制造“多重确认”。

## 六、数据来源与质量边界

行情和会员排名覆盖SHFE、INE、DCE、CZCE、GFEX。官方来源优先；部分品种使用明确标注的公开备用源，不将备用数据冒称官方。

真实报价与连续研究价使用的数据层分别如下；具体采集来源、日期及失败状态以每个品种的记录为准：

| 交易所 | 真实报价、成交量及持仓 | 自建后复权连续序列的原始行情 |
| --- | --- | --- |
| 上期所（SHFE）、上海能源中心（INE） | 交易所官方日报 | 官方逐合约日报 |
| 郑商所（CZCE） | 交易所官方日报 | 官方逐合约日报 |
| 广期所（GFEX） | 交易所官方接口 | 官方历史未完整取得，当前使用新浪逐合约日线；目标日与已验证官方快照核对 |
| 大商所（DCE） | 新浪具体合约日线；必要时使用通过下述校验的盘后快照 | 新浪逐合约日线；目标日与已验证快照核对 |

目前没有配置米筐账户或RQData接入流程。未来如接入，需另行取得账户及相应数据权限、实现采集与口径校验，并更新本节来源说明；凭证应保存在后台环境或GitHub Actions Secrets中，不写入前端或公开仓库。该接入尚未实现，不属于当前每日更新的数据来源。

| 数据 | 来源与处理原则 |
| --- | --- |
| 行情 | 上期所、能源中心、郑商所、广期所真实报价来自官方文件或接口；大商所采用已标注的新浪具体合约来源及匹配校验 |
| 会员排名 | 官方优先，仅为缺失的代表合约尝试东方财富备用；核对日期、具体合约、交易所、分页和独立名次，增减项缺失留空 |
| 仓单与库存 | 官方日报、XLSX、JSON及上期所库存周报；无法取得官方数据时使用单独标注的东方财富备用系列，不绕过访问验证 |
| 国内产业统计 | 国家统计局官方月度目录与指标，分别查询当期值、同比；累计值不差分成月度值，1—2月缺值不补零 |
| 农业预测 | 农业农村部CASDE大豆和植物油指定项目，区分市场年度、报告版本和预测修订 |
| 人工研究资料 | 原文核对后保存于国内研究JSON，包括部门、协会及行业报告，保留统计期、发布日、适用范围和缺失项 |

大商所日线未发布时，盘后快照只有在日期匹配、时间处于指定盘后窗口、昨收与昨结分别匹配前日日线、OHLC及量仓校验通过后才可使用；代表合约样本不混入全合约汇总。官方或备用排名的空结果、错日、缺页、名次缺口和重复会员不填入，也不抹去已有官方值。

上期所周报的库存小计与期货仓单分别读取；郑商所有效预报不算注册仓单；广期所接口未提供可核实单位时保留“接口计数”，不擅自折吨。实际覆盖、最新样本及失败状态均以页面为准，不在README中把某次采集数量当作永久覆盖承诺。

连续价格的原料来源另行标注：SHFE/INE/CZCE使用可核实的官方逐合约日报；DCE及官方历史未完整取得的GFEX使用新浪逐合约公开日线。备用来源必须与已验证快照的目标合约OHLC、成交量和持仓逐字段匹配；不执行接口响应中的脚本。研究序列是本站加工结果，不冒称数据商现成复权行情。初始覆盖与最早基准随有效样本而定，不宣称拥有长期完整历史。

### 四种日期不能混用

1. **行情日**：盘面快照对应的交易日期。
2. **统计期／数据日**：月度统计、周度库存或日报描述的时期。
3. **发布日期**：资料何时对市场公开；未提供或未核实时保持未知。
4. **检查／采集时间**：系统何时取得资料，不代替上述任何日期。

后续采集或修订资料可以用于当前交叉核对，但不能直接回填为历史时点已经知道的信息。缺少可核实发布时间的数据不用于宣称无前视偏差的基本面回测。

数据缺失不填零，不插值补造价格、库存或历史。不把期货持仓当实物库存，不把终端产量当单品消费。下载失败时保留原有有效序列与原日期，并披露失败状态；真实零仓单与缺失值严格区分。

## 七、每天更新什么

[每日工作流](.github/workflows/daily-update.yml)于北京时间**周一至周五18:17、20:17**检查盘后数据。GitHub调度可能延迟，也可从Actions手动触发。页面日期表示实际数据日期，不保证每天都有可发布的新一期。

- 行情、盘面因子、偏离事件和合约结构随成功的行情快照重算。
- 仓单、库存和已接入国内产业来源每天检查；周报、月报和年度预测按各自发布频率更新，不把旧值改标为当天数据。
- 人工研究事实与品种宏观传导框架需要核对原文后维护，尚不自动抓取新闻并改写结论。
- 在线版在成功部署后可读取新版本；下载到电脑的HTML是固定快照，需要重新下载。

行情刷新在临时目录采集、合并、计算和校验后再原子替换正式快照。错日、混合合约、已验证历史丢失、部分交易所采集失败或覆盖明显下降等会阻止发布；官方目标日文件404只记为尚无已发布报告，不直接判定为休市。席位缺失仍留空，晚间任务会再次检查备用排名。

网络容错：东方财富合约列表主入口请求失败时，依次使用同服务的 `82.push2.eastmoney.com`、`push2delay.eastmoney.com` 备用入口，并从第一页重新读取，不拼接不同入口的分页、不沿用旧合约列表。总数、唯一性和完整性仍须通过原有检查。所有入口均失败等请求异常会在30秒、90秒后重试整次行情刷新，目标日期固定，最多三次；数据校验错误立即失败。重试耗尽仍按失败报告并保留旧快照，GitHub可能发送失败邮件。2026-11-11、11-12（北京时间）的两次邮件对应东方财富合约列表返回HTTP 502，线上当时保留11月9日快照；不是关闭通知即可解决的问题。

原始成功下载可复用缓存，Git历史保留已提交快照。页面脚本使用内容版本号，更新后避免继续加载旧脚本。GitHub Pages需在仓库启用Actions发布，并设置变量 `ENABLE_GITHUB_PAGES=true`。工作流构建产物也提供离线HTML下载。

## 十、目前尚未解决的研究问题

- 缺少完整的现货基差、社会库存、连续订单、企业开工及真实消费链条，不能构成完整供需平衡表。
- 宏观事件、市场预期差和政策实际落地情况尚未自动接入，条件式传导路径不能替代事件核验。
- 统一窗口和阈值尚未分品种、季节与行情阶段校准，现有历史不足以支撑长期季节性或反转胜率结论。
- 当前没有完整策略回测、交易成本检验、收益预测或基本面因果识别；后复权研究收益也不等同实际可交易的连续策略收益。

下一步研究应补足能区分不同解释的证据：例如去库来自需求改善还是供应减少、反弹来自价均差修复还是新的驱动、上涨时的订单与现货是否跟进。在这些证据不足时，网站保留观察与分歧。
